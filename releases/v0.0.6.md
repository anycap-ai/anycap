AnyCap is under active development. Some capabilities listed below may not yet be available on your server -- the CLI automatically adapts and only shows commands that are ready to use.

## What's New

### Better Agent Guidance

- Model listing (`anycap image models`, `anycap video models`, etc.) now includes a hint prompting the agent to present available models and ask for user preference before generating.
- Generation results include a feedback hint with the request ID, guiding the agent to report issues via `anycap feedback`.

### All Commands Always Visible

- CLI no longer performs a preflight call to check server feature flags. All capability commands (image, video, music, drive, page) are registered unconditionally.
- When the server rejects a request due to feature gating, the CLI surfaces a clear error code and directs users to `anycap feedback --type feature` to request access.

### Installation

- Shell (recommended): `curl -fsSL https://anycap.ai/install.sh | sh`
- npm: `npm install -g @anycap/cli`
