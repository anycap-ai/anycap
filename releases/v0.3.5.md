## What's Changed

### Bug Fixes

- **Annotate UI restored in released binaries.** Earlier CLI builds embedded the Vite dev shell (`internal/cli/annotate/web/index.html`) instead of the bundled output (`internal/cli/annotate/page.html`). The dev shell only contains a `<script type="module" src="/src/main.ts">` reference, with no compiled JS/CSS, so `anycap annotate` opened a blank toolbar and unusable canvas in fresh installs and required a local `make annotate-ui` rebuild to work. v0.3.5 embeds the bundled `page.html` (matching `internal/cli/draw/`), and `anycap annotate` works out of the box again.
- **Feishu local resume no longer hijacks the next turn.** Saying `view or recover this conversation locally` now only returns the matching `codex resume <id>` command for you to run manually; the daemon will not silently resume that session on its next turn. `continue the local session` is still the explicit auto-resume verb.
- **Feishu owned conversations reply without an explicit binding.** Personal-bot conversations the daemon already owns are now treated as bound for reply purposes, so the bot answers in the original chat instead of falling back to the operator DM.
