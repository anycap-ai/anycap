## What's Changed

### Audio Generation

- **New `anycap audio` command group.** Discover live audio models and schemas, then generate audio with `anycap audio generate`.
- **Three input modes are supported.** Use text-to-audio, guide a result with one or more audio references, or generate a soundscape from an image.
- **Local references work directly.** Files passed through `--param audios=...` or `--param images=...` are uploaded automatically before generation.
- **Generated audio downloads automatically.** Final JSON includes the managed artifact URL, local path, MIME type, duration, size, usage, credits, and task diagnostics.

### Better Invocation Diagnostics

- Long-running model commands emit a machine-readable `invocation_started` event on stderr before waiting for the provider.
- Success and error JSON now carries available trace, request, provider task, upstream request, and controlled failure-stage fields.
- Server-error hints include a ready-to-run `anycap feedback` command with the original diagnostics, making failed provider calls easier to report and investigate.

### Media Output Handling

- Audio and music downloads use consistent output naming and safe extension fallbacks when provider URLs do not contain a filename extension.
