## What's New

### Web Search

`anycap search` brings web search to your agent with two modes:

**General search** returns a list of results with titles, URLs, descriptions, and full page content -- ideal for gathering information from multiple sources.

```bash
anycap search --query "Go error handling best practices"
```

**Grounding search** uses an LLM with real-time web access to synthesize an answer with per-segment source citations -- ideal for direct question answering.

```bash
anycap search --prompt "What is context engineering?"
```

### Web Crawl

`anycap crawl` converts any web page to clean Markdown -- one command to read any URL.

```bash
anycap crawl https://example.com
```

### Observability

The CLI now reports anonymous error telemetry (opt-out with `ANYCAP_NO_TELEMETRY=1`) and propagates trace context to the server for end-to-end debugging.

### Storage Quotas

Drive and Page now enforce per-user storage quotas. The CLI surfaces clear errors when limits are reached.

### Installation

- Shell (recommended): `curl -fsSL https://anycap.ai/install.sh | sh`
- npm: `npm install -g @anycap/cli`
