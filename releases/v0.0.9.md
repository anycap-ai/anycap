AnyCap is under active development. Some capabilities listed below may not yet be available on your server -- the CLI automatically adapts and only shows commands that are ready to use.

## What's New

### Sandbox and Container Support

The CLI now works cleanly in sandboxed environments (Codex, Docker, agent containers) where the home directory or OS keychain is not persistent. Two new environment variables control where state is stored:

```bash
export ANYCAP_CONFIG_DIR=./.anycap   # store config in the working directory
export ANYCAP_NO_KEYRING=1           # disable OS keychain, use file storage
```

With both set, config, credentials, and update markers all live in the working directory and survive container restarts. See `docs/guides/sandbox-setup-prompt.md` for a copy-paste setup prompt you can hand to any agent.

### Better Agent Compatibility

`image read`, `video read`, and `audio read` now accept `--prompt` as a hidden alias for `--instruction`. Agents that reuse generation-style flags no longer hit "unknown flag" errors.

### Installation

- Shell (recommended): `curl -fsSL https://anycap.ai/install.sh | sh`
- npm: `npm install -g @anycap/cli`
