## What's New

### Interactive Annotation and Feedback

`anycap annotate` opens an interactive browser UI for collecting structured visual feedback from humans -- drawing, labeling, and screen recording on images, URLs, videos, and audio files.

```bash
# Annotate an image (blocking -- waits for Done click)
anycap annotate photo.png -o feedback.png

# Review a URL with screen recording
anycap annotate https://example.com

# Non-blocking mode for agent workflows
anycap annotate design.png --no-wait --bind 0.0.0.0 --port 8888
```

**Collaboration:** Image, video, and audio sessions support real-time multi-user collaboration -- shared annotations, live cursors, and participant indicators. URL mode is single-user because the screen recording is the primary feedback artifact.

**Screen recording:** The Rec button captures the full browser tab as video. Use `anycap actions video-read` on the recording for AI video understanding of the feedback session.

**Session management:**

```bash
anycap annotate list                        # List active sessions
anycap annotate poll --session ann_xxx      # Get latest result
anycap annotate stop --session ann_xxx      # Stop background server
```

**Done button:** In blocking mode, clicking Done ends the session. In non-blocking mode, Done saves annotations without ending the session -- other collaborators see a toast and can keep editing.

**Reverse proxy support:** The annotation UI works behind reverse proxies with arbitrary path prefixes. All URLs resolve relative to the page, and query parameters are preserved.

### Image Edit Consolidation

`anycap image edit` has been removed. Use `anycap image generate --mode image-to-image` instead -- same capability, simpler interface.

### New Skills

- **anycap-human-interaction** -- guides agents through annotation workflows for URL review, image markup, video/audio feedback, and iterative refinement.
- **anycap-media-production** -- guides agents through image/video/music generation and delivery.

### Installation

- Shell (recommended): `curl -fsSL https://anycap.ai/install.sh | sh`
- npm: `npm install -g @anycap/cli`
