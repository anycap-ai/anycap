## Bug Fixes

### Longer timeout for slow capabilities

Video generation, music generation, and other long-running capabilities could fail with a timeout error. The default request timeout has been increased from 2 minutes to 10 minutes on both the CLI and server side.

### Login reliability improvements

- The CLI now routes all logins through Google authentication for a more consistent experience.
- Stale or invalid credentials are now properly detected, so the CLI no longer skips the login flow when credentials have expired.

### Installation

- Shell (recommended): `curl -fsSL https://anycap.ai/install.sh | sh`
- npm: `npm install -g @anycap/cli`
