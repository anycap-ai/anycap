## What's New

### OAuth Authentication
- Login flows now return OAuth tokens with automatic refresh, replacing static API keys.
- `credentials set-key` command for direct API key input (CI/CD, scripted provisioning).
- `credentials show` to inspect current auth status.

### CLI Config (TOML)
- Config format migrated from JSON to TOML (`~/.anycap/config.toml`).
- New `config` command: `get`, `set`, `unset`, `show`, `keys`.

### Feature Flags
- Capabilities are gated by feature flags (env, ldflags, or server-pushed).
- `image understand` and `video read` enabled by default.

### Multi-Image Understand
- `image understand` now accepts multiple `--url` and `--file` flags (up to 10 images per request).

### Feedback
- New `feedback` command: `anycap feedback --type bug --message "..."`.

### Structured Errors
- All CLI output includes `request_id` for traceability.
- Errors return machine-readable codes with recovery hints.

### Skill Management
- New `skill list`, `skill show`, `skill install` commands.

### Installation
- npm: `npm install -g @anycap/cli`
- Shell: `curl -fsSL https://anycap.ai/install.sh | sh`
