AnyCap is under active development. Some capabilities listed below may not yet be available on your server -- the CLI automatically adapts and only shows commands that are ready to use.

## What's New

### Login Works Everywhere

`anycap login` now automatically falls back to device-code flow when no browser is available. Docker, WSL, SSH, and headless Linux environments just work -- no extra flags needed.

### Trace ID for Debugging

Every CLI call now prints a trace ID in its output. When something goes wrong, pass it to `anycap feedback --trace-id trc_xxx` so we can look it up immediately.

### Smarter Update for npm Users

`anycap update` detects npm-installed binaries and shows the correct `npm install -g @anycap/cli` command instead of trying to self-replace. Shows "already up to date" when current.

### Upload Size Limits

Video and audio uploads are capped at 100 MB with a clear message and `ffmpeg` compression tip when exceeded.

### Installation

- Shell (recommended): `curl -fsSL https://anycap.ai/install.sh | sh`
- npm: `npm install -g @anycap/cli`
