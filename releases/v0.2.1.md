## What's New

### Interactive Whiteboard (Draw)

`anycap draw` opens a browser-based interactive whiteboard powered by Excalidraw. Create and iterate on diagrams, architecture charts, flowcharts, and wireframes collaboratively with humans.

```bash
# Open a blank whiteboard (blocking -- waits for Save click)
anycap draw

# Pre-populate with a Mermaid diagram (auto-converted to editable shapes)
anycap draw --init arch.mmd

# Non-blocking mode for agent workflows (recommended)
anycap draw --init arch.mmd --no-wait --port 18400

# Push updated content to an active session without restarting
anycap draw update --session drw_xxx --init updated.mmd
```

**Input formats:** Mermaid (`.mmd`, `.mermaid`), Excalidraw JSON (`.excalidraw`), images (set as background), or blank canvas.

**Collaboration:** Multiple users can open the same draw URL simultaneously with real-time sync via WebSocket -- shared shapes, live cursors, and participant indicators.

**Session management:**

```bash
anycap draw list                        # List active sessions
anycap draw poll --session drw_xxx      # Get latest snapshot
anycap draw stop --session drw_xxx      # Stop background server
```

### Multiple Reference Images

Image generation now supports multiple reference images for style transfer, composition blending, or subject-driven generation via JSON array syntax:

```bash
anycap image generate \
  --prompt "combine the architecture style with the color palette" \
  --model nano-banana-2 \
  --mode image-to-image \
  --param images='["./style-ref.png","./color-ref.png"]' \
  -o blended.png
```

### Skills Install Hint

`anycap status` now includes a `hint` field in JSON output guiding agents and users to install or update AnyCap skills via `npx -y skills add`.

### Installation

- Shell (recommended): `curl -fsSL https://anycap.ai/install.sh | sh`
- npm: `npm install -g @anycap/cli`
