## Bug Fixes

### Fix CLI hang on headless Linux

The CLI could hang indefinitely during login or credential access on headless Linux environments (SSH sessions, Docker containers, AI agent sandboxes). This happened because `gnome-keyring-daemon` is unavailable in these environments, causing D-Bus calls to block forever.

**What changed:**

- The CLI now auto-detects headless Linux (no `DISPLAY` or `WAYLAND_DISPLAY`) and skips the OS keychain entirely, falling back to the credential file.
- All keyring operations now have a 3-second timeout as an additional safety net.
- You can still explicitly disable the keychain with `ANYCAP_NO_KEYRING=1`.

### Installation

- Shell (recommended): `curl -fsSL https://anycap.ai/install.sh | sh`
- npm: `npm install -g @anycap/cli`
