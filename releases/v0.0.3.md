## What's New

### Headless Login

- `anycap login --headless` for environments without a browser (SSH, containers, CI).
- Non-blocking mode: `anycap login --headless --no-wait --json` returns a login URL and session ID immediately.
- Resume with `anycap login poll --session <id> --wait --json` after the user completes browser auth.

### Video Generation

- New `anycap video generate` command.
- Supports `--param duration=<seconds>`, `--param ratio=<w:h>`, and model-specific parameters.

### Unified Parameter Syntax

- All generate commands (`image generate`, `video generate`) now use `--param key=value` for capability parameters, replacing per-flag options.

### Model Hints and Schema

- `anycap models <model> schema` now shows capability-level constraints (supported durations, aspect ratios, resolutions) fetched from the platform.
- New models available: nano-banana-pro, seedream-4.5, seedream-5.

### Improved Error Messages

- Upstream validation errors (e.g. unsupported video duration) are now surfaced as clear parameter errors instead of opaque "internal server error".
- Auth errors include a hint for `--headless` login in non-browser environments.
- All action responses now include a `"status"` field for consistent parsing.

### Auto-Download

- `image generate` automatically downloads generated images and outputs local file paths.

### Bug Fixes

- Hardened self-update for npm-installed CLIs and dev builds.
- Tightened headless login resume flow to prevent token replay.
- Fixed credential loading for verified device sessions.

### Installation

- npm: `npm install -g @anycap/cli`
- Shell: `curl -fsSL https://anycap.ai/install.sh | sh`
