AnyCap is under active development. Some capabilities listed below may not yet be available on your server -- the CLI automatically adapts and only shows commands that are ready to use.

## What's New

### Drive Storage

- `anycap drive ls` / `mkdir` / `mv` / `rm` / `upload` / `share` for cloud file management.

### Page Hosting

- `anycap page deploy` deploys a directory or single HTML file as a static site.
- Full lifecycle: `list` / `info` / `delete` / `publish` / `unpublish` / `rollback` / `versions` / `set`.

### Image Edit

- New `anycap image edit` command for image-to-image editing.

### Local File Upload in Generate

- Pass local file paths directly: `--param images=./photo.png`.
- The CLI auto-uploads and substitutes URLs.

### Music Generation

- New `anycap music generate` command.

### Audio Analysis

- New `anycap audio read` command.

### Improvements

- Clearer error messages for quota and parameter validation.
- New models: Seedance 1.5 Pro, Kling 3.0, ElevenLabs Music.

### Installation

- npm: `npm install -g @anycap/cli`
- Shell: `curl -fsSL https://anycap.ai/install.sh | sh`
