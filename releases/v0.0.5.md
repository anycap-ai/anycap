AnyCap is under active development. Some capabilities listed below may not yet be available on your server -- the CLI automatically adapts and only shows commands that are ready to use.

## What's New

### Reliable Self-Update and Install

- `anycap update` and `install.sh` now resolve the latest release via GitHub redirect instead of the REST API, eliminating the unauthenticated rate limit (60 req/hr) that could cause update checks to fail.
- Asset URLs are constructed from the goreleaser naming convention, so no API call is needed at all.

### Installation

- Shell (recommended): `curl -fsSL https://anycap.ai/install.sh | sh`
- npm: `npm install -g @anycap/cli`
