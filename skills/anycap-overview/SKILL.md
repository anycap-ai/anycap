# AnyCap Skill Index

AnyCap is a capability runtime for AI agents.

## Install

1. Build or install the CLI.
2. Configure the server endpoint if needed.
3. Run `anycap login` once.

## Core Commands

- `anycap status` -- check connectivity and auth status
- `anycap image models` -- list available image generation models
- `anycap image generate --prompt "..."` -- generate an image
