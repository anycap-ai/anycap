## Key Decisions Captured

1. AnyCap 的 SEO 第一階段應該先補「可索引的高意圖頁面」，不是先大量寫 blog。
2. sitemap `500` 是目前最高優先級的技術 SEO 問題。
3. 搜尋策略應優先攻長尾 category / capability / framework intent，而不是搶泛大詞。
4. 後續頁面擴張主軸應是 `capabilities`、`for/*`、`guides`、`compare`、`glossary`。
