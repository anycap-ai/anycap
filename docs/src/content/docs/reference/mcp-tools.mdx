`anycap mcp` exposes 23 tools through a local stdio server.

## Authentication

| Tool | Purpose |
| --- | --- |
| `anycap_auth_status` | Inspect the shared local credential state |
| `anycap_login` | Start device authorization without opening a browser at startup |
| `anycap_login_poll` | Complete a previously started login session |
| `anycap_logout` | Delete persistent local credentials |

No authentication tool returns raw credentials. Logout cannot clear an active `ANYCAP_API_KEY` environment value or revoke a remote credential.

## Status and discovery

| Tool | Purpose |
| --- | --- |
| `anycap_status` | Check account and server state |
| `anycap_list_models` | Discover current models by capability |
| `anycap_model_schema` | Retrieve the exact selected operation and mode contract |

- `anycap_page_list`

<Aside type="note" title="Mutation boundary">
The current MCP surface does not expose Drive uploads, shares, deletes, or Page deployments. Use the CLI for those write operations.
</Aside>

## Local media tools

Seven tools accept HTTP(S) URLs, existing AnyCap upload references, or authorized local paths:

- image generate, edit, upscale, and read
- video generate and read
- audio read

See [Security and local file access](/reference/security/) before granting roots.
